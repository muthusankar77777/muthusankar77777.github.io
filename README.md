## 🌌 Interactive Features & Live Sandboxes

The website is designed with an immersive **Quantum & Deep-Space Cyber** aesthetic, featuring:

- **⚛️ Interactive BB84 Quantum Key Distribution Simulator**:
  - Transmit polarized photons between Alice and Bob via a simulated CubeSat LEO relay.
  - Toggle an Eavesdropper (Eve) to observe quantum state collapse and protocol abort mechanics.
- **🛡️ STM32F446RE Secure Bootloader Emulator**:
  - Simulate cryptographic signature verification (SHA-256 / ECDSA) and AES-256 payload decryption.
  - Live flash memory map inspector showing rollback prevention and vector table remapping.
- **🎵 SOFI Sound Fidelity & Huffman DSP Visualizer**:
  - Real-time oscilloscope canvas rendering dynamic audio waveforms with frequency/amplitude harmonics.
  - Live entropy calculator demonstrating 100% lossless decoding accuracy.
- **✨ Cosmic Particle Constellation**:
  - Physics-driven canvas particle network with interactive cursor attraction and quantum entanglement links.
- **📱 Responsive Glassmorphic Design**:
  - Tailored with Tailwind CSS, Lucide icons, and modern CSS3 backdrop filters.
